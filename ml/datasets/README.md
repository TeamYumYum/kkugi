# datasets — 데이터셋 빌드

관리자 웹에서 **승인된 수정 데이터**(예측 vs 수정)를 읽어 학습용 데이터셋을 만든다.

- 입력: Spring 업무 DB의 `meal_prediction`·`meal_correction`·`correction_review`(승인분). **읽기 전용** 계정으로 접근한다.
- 출력: 이미지 경로·라벨 목록과 학습/검증/평가 분할. 버전 태그(예: `v1`, `v2`)를 붙여 MLflow 데이터셋 또는 run 태그로 남긴다.
- 원본 이미지와 빌드 산출물은 커밋하지 않는다(저장 위치는 결정 필요).
- 평가 분할은 버전 간 비교가 가능하게 고정한다.

할 일(MVP-3): 빌드 스크립트, 분할 규칙, 클래스(음식) 목록 동기화 방법.
