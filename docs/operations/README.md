# 운영 문서

서비스를 띄우고 지키는 데 필요한 절차를 둔다. 규칙을 새로 정의하지 않고 규칙 문서를 링크한다.

| 문서 | 내용 | 소유 | 상태 |
|---|---|---|---|
| [1주차 기반 체크리스트](./week1-checklist.md) | 1주차 금요일에 셸·규칙 파일·설계 문서·계약·인프라·로그인 왕복을 확인하는 목록 | C 정리, 항목별 홈 담당 | 초안 |
| [Runbook](./runbooks/README.md) | 배포, 롤백, 데모 절차 | C | 초안 |
| 운영 안내서 | 서비스 구성, 운영 도구, 모니터링, 권한, 담당자 | C | 배포 환경이 정해지면 작성. 그 전에는 [infra/README.md](../../infra/README.md)가 로컬 통합 실행을 안내한다 |

- Runbook은 따라 하는 절차이고, 운영 안내서는 무엇이 어디에 있는지의 지도다. 같은 내용을 둘 다에 쓰지 않는다.
- 데모·동결 시점의 태그 규칙은 [Git 컨벤션 4장](../git-convention.md), 태그 절차는 [개발 흐름 7장](../development-workflow.md)이 기준이다.
- Secret 취급은 [Secret 규칙](../secret-environment-variables.md)을 따른다. 이 폴더의 문서에 실제 값을 쓰지 않는다.
