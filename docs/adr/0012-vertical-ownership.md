# ADR-0012: 개인 수직 소유 4 + 횡단 2, Workout만 페어 — 리뷰어는 상대 표면 홈 담당

| 항목 | 값 |
|---|---|
| 상태 | 채택 |
| 결정일 | 2026-10-03 |
| 결정자 | 리뉴얼 기획 단계 팀 결정 (E 주도) |
| 관련 | [기획서](../renewal/plan.md) |

## 맥락

6인·8주. 표면 5개(폰·워치·웹·Spring·FastAPI/ML). 도메인 6개 중 제품 도메인 4개(Member+Growth, Meal, Workout, Coaching), 능력/표면형 2개(AI/ML, Web).
팀 6명 중 **4명 이상이 Compose와 Spring을 둘 다 직접 쓸 수 있다.** Claude Code로 코드 대부분을 생산한다.
작업량 추정 합계 ≈ 7.7인분 → 1.7인분 초과. 선택지: 표면 분담 / 페어 수직 / 개인 수직.

## 결정

| 사람 | 수직 소유 (폰 + 백엔드 + 마이그레이션, 1 Story = 1 Branch) | 홈 표면 (공통 기반 소유 · 그 표면 PR 리뷰) |
|---|---|---|
| A | Meal | Android 폰 |
| B | Workout — 폰 + 워치 전체 + Data Layer | Wear |
| C | Member + Growth | 인프라 · CI/CD |
| D | Coaching | Spring |
| E | AI/ML 플랫폼 (횡단 능력) | FastAPI · ml/ |
| F | Web (횡단 표면) · **3~5주차 Workout 페어** | Web |

규칙:
1. **1 Story = 1 Branch = 1 PR.** 폰·백엔드·마이그레이션을 한 브랜치에. `develop` 없음, `main` 직접 머지.
2. **PR 리뷰어 = 상대 표면 홈 담당.** A가 쓴 Spring 코드는 D가, D가 쓴 Compose는 A가 본다.
3. **공통 변경**(`:core`, `global/`, `components/`, CI)은 홈 담당 승인 필수.
4. **계약 변경**(`contracts/`, `ai/schemas`)은 소비 측 담당 리뷰 필수.
5. 기반 스프린트(1주차)는 홈 표면 담당이 각자 셸을 세운다. 수직 스토리는 2주차부터.

## 근거

- **핸드오프 비용 제거.** "백엔드는 됐는데 화면이 안 붙음" 상태가 없다. 스토리 완료 = 사용자가 쓸 수 있는 변화 하나.
- **Claude Code 효율이 최대.** 한 사람이 스토리의 전 컨텍스트를 들고 있다.
- **4명 풀스택이면 개인 수직이 현실적.** 페어는 풀스택이 0~1명일 때의 안전장치였다.
- **Workout만 페어인 이유**: 폰 + 워치 + Data Layer로 유일하게 1.5인분. 웹(F)은 MVP-3(5~7주)이 본게임이라 3~5주차가 비어 있고, 그 시점이 정확히 Workout 피크(MVP-2)다.
- **리뷰어 = 상대 표면 홈 담당**이 개인 수직의 유일한 일관성 장치다. 이게 없으면 6명이 각자 스타일로 Spring을 쓴다. 가드레일 규칙 파일이 이 리뷰의 체크리스트가 된다.

## 고려한 대안

- **표면 분담(안드2·백2·웹1·AI1)**: 전문성 깊이. 핸드오프 비용, "내 파트 완료" 문화. 기각.
- **페어 수직(Pair1 Member·Meal·Growth / Pair2 Workout·Coaching)**: 안전하지만 페어 내 일일 조율 필요. 풀스택 4명이면 불필요. 기각.
- **순수 1인 1도메인 전 표면(웹까지)**: 도메인 크기 2배 차이(Workout vs Member), 웹·AI는 도메인이 아니라 표면/능력, 공통 기반에 주인 없음. 기각.

## 결과

- 한 사람이 막히면 그 도메인이 멈춘다 → 주 1회 도메인 데모(내부)로 조기 발견. 리스크 표에 기록.
- 익숙하지 않은 표면 코드의 품질은 **규칙 파일 품질에 의존**한다 → 가드레일 키트의 실전 테스트. 1주차 끝에 규칙 파일이 완성돼 있어야 한다.
- 범위 초과 1.7인분은 **RAG 최후순위 + 관리자 최소 + 커뮤니티 제외**로 흡수한다. 7주 말 기능 동결.
- 팀원 실명 → A~F 매핑은 미결. 풀스택 4명을 A·B·C·D에.
